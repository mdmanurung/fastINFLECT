# Package index

## Run an analysis

- [`INFLECT()`](https://mdmanurung.github.io/fastINFLECT/reference/INFLECT.md)
  : Run a fastINFLECT metaclustering scan
- [`inflect_adaptive_set_i()`](https://mdmanurung.github.io/fastINFLECT/reference/inflect_adaptive_set_i.md)
  : Build an explicitly bounded adaptive k schedule

## Read and plot results

- [`print(`*`<inflect.results>`*`)`](https://mdmanurung.github.io/fastINFLECT/reference/print.inflect.results.md)
  : Print candidate values from a fastINFLECT result
- [`summary(`*`<inflect.results>`*`)`](https://mdmanurung.github.io/fastINFLECT/reference/summary.inflect.results.md)
  : Summarize a fastINFLECT result
- [`plot(`*`<inflect.results>`*`)`](https://mdmanurung.github.io/fastINFLECT/reference/plot.inflect.results.md)
  : Plot the fastINFLECT QC pass-rate curve
- [`as.data.frame(`*`<inflect.results>`*`)`](https://mdmanurung.github.io/fastINFLECT/reference/as.data.frame.inflect.results.md)
  : Extract tested fastINFLECT QC scores
- [`marker.performance()`](https://mdmanurung.github.io/fastINFLECT/reference/marker.performance.md)
  : Plot marker-level QC pass rates

## Build a custom workflow

- [`iteration.metacluster()`](https://mdmanurung.github.io/fastINFLECT/reference/iteration.metacluster.md)
  : Run iterative metaclustering on SOM-clustered objects
- [`iteration.QC()`](https://mdmanurung.github.io/fastINFLECT/reference/iteration.QC.md)
  : Score marker-level QC criteria across metaclustering schedules
- [`FlowSOMQC()`](https://mdmanurung.github.io/fastINFLECT/reference/FlowSOMQC.md)
  : Score one SOM metaclustering with dip and IQR criteria
- [`metaClusteringhclust()`](https://mdmanurung.github.io/fastINFLECT/reference/metaClusteringhclust.md)
  : Hierarchical (Ward) metaclustering of SOM codes

## Inspect selection diagnostics

- [`QC.to.curve()`](https://mdmanurung.github.io/fastINFLECT/reference/QC.to.curve.md)
  : Plot a criterion-specific fastINFLECT QC curve
- [`inflect_kneedle()`](https://mdmanurung.github.io/fastINFLECT/reference/inflect_kneedle.md)
  : Locate the knee of a diminishing-returns curve (Kneedle)
- [`inflect_threshold_k()`](https://mdmanurung.github.io/fastINFLECT/reference/inflect_threshold_k.md)
  : Smallest k that reaches a target QC pass rate
- [`Lfunction()`](https://mdmanurung.github.io/fastINFLECT/reference/Lfunction.md)
  : Lfunction for determining Inflection Point
- [`leastError()`](https://mdmanurung.github.io/fastINFLECT/reference/leastError.md)
  : Determine kneepoint by minimizing fitting errors
- [`computemode()`](https://mdmanurung.github.io/fastINFLECT/reference/computemode.md)
  : Estimate the mode of a numeric vector
- [`bimodality.coefficient()`](https://mdmanurung.github.io/fastINFLECT/reference/bimodality.coefficient.md)
  : Sarle's bimodality coefficient
