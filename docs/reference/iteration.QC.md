# Run unimodality quality control on metaclusterings in parallel

Unimodality score is calculated for all calculated metaclusterings. This
is the central fast reimplementation of the original INFLECT QC sweep:
each distinct SOM-node subtree is evaluated once, then the per-k
accuracy matrices are assembled from that cache. The marker-level
pass/fail definition remains aligned with the original `FlowSOMQC()`
method.

## Usage

``` r
iteration.QC(
  FlowSOM.results,
  metaclustering.list,
  set.i,
  multicore = TRUE,
  cores = NULL,
  zeroes.in = FALSE,
  only.clustering.markers = TRUE,
  acquired_markers = NULL,
  uniform.test = c("both", "spread", "unimodality"),
  th.pvalue = 0.05,
  th.IQR = 2,
  verbose = FALSE,
  max.n.diptest = NULL,
  seed = 1L,
  ...
)
```

## Arguments

  - FlowSOM.results:
    
    A supported SOM object with completed SOM clustering. Supports
    FlowSOM objects and kohonen objects returned by `som` or `xyf`.

  - metaclustering.list:
    
    List of metaclustering results, as generated by
    [iteration.metacluster](https://mdmanurung.github.io/fastINFLECT/reference/iteration.metacluster.md)

  - set.i:
    
    Vector containing either the desired iterations to be tested

  - multicore:
    
    logical, should the QC sweep be run in parallel (fork-based
    `mclapply` over distinct SOM-node subtrees on Unix). Ignored on
    Windows. Default is `TRUE`

  - cores:
    
    If `multicore == TRUE`, number of cores to be used. If `NULL` max
    number of cores-1 is used.

  - zeroes.in:
    
    Should be values at and below `0` be included. Recommeded default
    for mass cytometry data is `FALSE`

  - only.clustering.markers:
    
    If `TRUE` only evaluates markers specified as clustering markers.
    For kohonen objects this is the first data layer.

  - acquired\_markers:
    
    Vector of column names with marker data to be evaluated by
    fastINFLECT. Ignored if `only.clustering.markers == TRUE`

  - uniform.test:
    
    What tests are performed per marker per cluster. Options are "both",
    "spread" , or "unimodality" as a string.

  - th.pvalue:
    
    Threshold for rejecting Unimodality dip.test result. Default is
    `0.05`. For more information see
    [dip.test](https://rdrr.io/pkg/diptest/man/dip.test.html)

  - th.IQR:
    
    Threshold for rejecting marker distribution based on inter-quartile
    range. Default is arc-sinh transformed value of `2`.

  - verbose:
    
    `logical` , default is `FALSE`

  - max.n.diptest:
    
    Optional integer. If set, each (cluster, marker) sample is randomly
    subsampled to at most this many events before the dip test. This
    removes the sample-size sensitivity of the dip test (large clusters
    otherwise make it reject unimodality for trivial deviations) at the
    cost of direct legacy-score comparability. Subsampling is seeded and
    therefore deterministic. Default `NULL` preserves the legacy scoring
    path.

  - seed:
    
    Integer base seed used for the optional subsampling. Default `1L`.

  - ...:
    
    Additional arguments to pass to `dip.test` through `FlowSOMQC`.

## Value

A `list` with 2 items. The first is the unimodality scores stored in
U.set. Second is a `list` with a `logical` matrix for each
metaclustering result.
